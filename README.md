# AMHK Web

Proyecto básico de AMHK con Node.js y Express.

## Ejecutar localmente

1. Instala Node.js.
2. Dentro de esta carpeta ejecuta `npm install`.
3. Ejecuta `npm start`.
4. Abre `http://127.0.0.1:3000`.

Endpoint de prueba: `/api/status`

Este proyecto es una página de demostración. Todavía no incluye generación/validación de claves ni integración confirmada con Happ Proxy.
